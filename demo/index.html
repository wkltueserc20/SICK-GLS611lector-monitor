使用說明與儲存位置

這是什麼？

這是 Windows Rust 監控程式的互動展示。正式版接收 SICK Lector611 Liquid Lens 的照片及 XML；這裡完全以瀏覽器產生模擬結果。

建議體驗順序

選擇一台或十台 → 選擇模擬對象 → 按「模擬 NG」→ 再按「模擬 OK」，觀察最新照片恢復 OK，而最近 NG 仍保留。點照片可放大及旋轉。

設備設定

可調整名稱、IP、FTP 埠、啟用狀態與排序。儲存後立即套用展示；正式版需重新開啟程式。匯入匯出僅處理 JSON 設定，不含照片。

暫停的差異

「暫停畫面」只凍結顯示，模擬仍繼續。「自動模擬：關」停止自動產生新結果，仍可手動模擬 OK／NG。

展示資料

示意圖片並非現場照片，圖中的點陣紋理不是可解碼條碼；條碼文字為預先產生的假資料。關閉網頁不影響任何設備。設備數量快捷鍵會重設展示設定。

設備與接收設定

管理 1～10 台展示設備 · 儲存後立即套用，僅影響此瀏覽器

設備可以共用 FTP 埠，由來源 IP 區分。這裡僅模擬設定，不會發送網路請求至設備；正式部署才需同步設定 SOPAS 與防火牆。

設備清單

勾選啟用才會接收並顯示；上下移動可調整畫面順序。

啟用設備名稱來源 IPv4FTP 接收埠排序／刪除

FTP 埠留空時使用預設值。資料夾使用固定識別碼，更改名稱或 IP 不會變更資料位置。刪除設備只移除設定，不會刪除照片；需要暫時停用請取消勾選。

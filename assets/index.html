使用說明與儲存位置

最新照片與歷史 NG

「最新讀碼」每次收到照片就更新。XML 尚未傳到時顯示「等待判定」，無法辨識結果時顯示「待確認」。「最近 NG」僅在收到新的 NG 時更新。

暫停與關閉

暫停畫面不影響背景接收。關閉整個監控應用程式視窗，才會停止照片接收。

照片儲存位置

讀取中…

photos：一般照片；ng_photos：NG 照片，各自依設備固定識別碼分資料夾（舊設備沿用原 IP 資料夾），更改 IP 不會拆開歷史資料。每個 IP 兩者合計保留最新 1,000 張，超過自動刪除最舊照片及其 XML。data 保存最新及 NG 快取。

關於接收狀態

「接收服務正常」表示程式正在回應，不代表各台相機都在線。多久沒有新照片，取決於設備是否有觸發讀碼。

設備與接收設定

管理 1～10 台設備 · 儲存後需關閉並重新開啟程式

設備可以共用 FTP 埠，由來源 IP 區分。修改此處不會變更設備本身的網路設定；請同步設定 SOPAS 的 FTP 目的地與電腦防火牆。

設備清單

勾選啟用才會接收並顯示；上下移動可調整畫面順序。

啟用設備名稱來源 IPv4FTP 接收埠排序／刪除

FTP 埠留空時使用預設值。資料夾使用固定識別碼，更改名稱或 IP 不會變更資料位置。刪除設備只移除設定，不會刪除照片；需要暫時停用請取消勾選。

設定備份

匯出目前表單（含尚未儲存內容）。匯入後檢查並按儲存才會生效。

照片與 NG 合計套用每台保留上限；調低上限後，重開時會清除超額的舊照片。備份 JSON 不含照片。

儲存不會中斷目前接收；重新開啟後套用。

使用說明與儲存位置

最新照片與歷史 NG

「最新讀碼」每次收到照片就更新。XML 尚未傳到時顯示「等待判定」，無法辨識結果時顯示「待確認」。「最近 NG」僅在收到新的 NG 時更新。

暫停與關閉

暫停畫面不影響背景接收。關閉整個監控應用程式視窗，才會停止照片接收。

照片儲存位置

讀取中…

photos：一般照片；ng_photos：NG 照片，各自依設備 IP 分資料夾。每個 IP 兩者合計保留最新 1,000 張，超過自動刪除最舊照片及其 XML。data 保存最新及 NG 快取。

關於接收狀態

「接收服務正常」表示程式正在回應，不代表四台相機都在線。多久沒有新照片，取決於設備是否有觸發讀碼。
